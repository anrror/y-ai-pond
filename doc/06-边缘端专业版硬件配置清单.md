> **为什么 3 套**: 进水口 ×1 (水源监控) + 池中心 ×1 (代表值) + 出水口 ×1 (排放监控) = 全水体覆盖。任意 1 套故障，剩余 2 套交叉验证，系统不降级。

## 4. 关键差异解读

### 4.1 为什么工业探头贵 5-10 倍？

| | DFRobot SEN0237-A (标准版) | 雷磁 DOG-3082 (专业版) |
|---|---|---|
| **原理** | 极谱法 (消耗氧气, 需搅拌) | **荧光法** (不消耗, 静止可用) |
| **寿命** | 12-18 月 (换膜/填充液) | **3 年+** (荧光帽替换) |
| **标定** | 手动两点校准 | 出厂已标定, 可溯源至 NIST |
| **输出** | 0-3.3V 模拟 (需 ADC) | **RS-485 Modbus 数字** (直接读) |
| **诊断** | 无 | 膜完整性/光源衰减/温度异常自诊断 |
| **维护** | 每周清洗 + 每月换膜液 | **自清洁雨刷, 季度检查** |
| **证书** | 无 | CMA 计量证书 (可送第三方) |

**结论**: 3 年 TCO 其实差不多。极谱法每年耗材 ¥600+ ×3 年 = ¥1,800 + 人工清洗 1h/周 ×150 周 ×¥30 = ¥4,500。荧光法 3 年耗材 ¥0 + 人工 0.5h/季 ×12 季 ×¥30 = ¥180。差价被耗材和人工吃回去了。

### 4.2 为什么摄像头从 ¥250 变 ¥1,200？

| | MIPI CSI 模组 (标准版) | GigE Vision 工业相机 (专业版) |
|---|---|---|
| **传输距离** | ≤30cm (排线) | **≤100m** (网线, PoE) |
| **供电** | 单独 12V 电源线 | **PoE, 一根网线** |
| **防护** | 自己装壳黏胶 | 出厂 IP67, 气压测试报告 |
| **标定** | 无 | 出厂畸变校正参数 |
| **接口** | MIPI (RK3588 专用) | **GigE (任意设备可读)** |
| **SDK** | Rockchip 私有 | **GenICam 标准 (跨厂商)** |

### 4.3 防爆为什么重要？

饲料粉尘是可燃粉尘。投喂机附近粉尘浓度在投喂瞬间可达爆炸下限。普通配电箱 (IP65) 不防爆。专业版：

- 配电柜: Ex d IIC T6 隔爆型, 即使内部产生火花也不会引燃外部粉尘
- 所有穿线孔: Ex d 防爆电缆引入装置
- 执行器: 本安型 (Ex ia) 或隔爆外壳内

这不是"贵一点"，是**合规生产的底线**。安监检查不过，停产整改损失远超省下的几千块。

## 5. 何时选专业版？

| 场景 | 推荐版本 |
|------|---------|
| 1-3 个小鱼塘, 家庭/个体户经营 | 标准版 |
| 5-20 个鱼塘, 养殖企业 | 标准版 ×N + 云端集群调度 |
| **政府/大型企业招投标项目** | **专业版** (资质证书齐全, 合规验收) |
| **科研/高校实验基地** | **专业版** (数据可计量可追溯, 支持论文发表) |
| **高密度/高价值养殖** (对虾/石斑/三文鱼) | **专业版** (不能承受设备故障, 死一塘损失 20-100 万) |
| **饲料粉尘严重区域** | **专业版** (防爆是强制要求) |
| **极端气候地区** (-20°C 或 45°C+) | **专业版** (宽温 + 恒温柜) |
| **无市电偏远基地** | **专业版** (太阳能方案必须足量) |
