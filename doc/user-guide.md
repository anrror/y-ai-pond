## 1. 系统简介

y-ai-pond 是面向水产养殖基地的**三态智能管理平台**，通过 Web Dashboard 让您在一个网页里管理整个养殖基地：

- **农场管理**：创建和管理多个养殖基地（农场），每个农场下可划分多个池塘。
- **设备管理**：注册和管理边缘控制器、传感器节点等设备，查看在线状态。
- **实时监控**：实时查看池塘水质（pH、溶解氧、水温、氨氮、浊度、水位）与摄像头画面。
- **投喂控制**：手动投喂、自动投喂、AI 推荐投喂三种方式。
- **告警管理**：水质异常自动告警，及时处理避免损失。
- **数据导出**：导出传感器历史数据与投喂日志。
- **数字孪生**：大型基地可启用水体仿真，推演极端天气下的投喂策略。

> **重要说明**：本系统采用"边缘端毫秒级实时控制 + 云端策略优化"架构。投喂电机的实时控制由部署在池塘现场的**边缘控制器**完成（不依赖网络），Web Dashboard 负责**远程监控、配置与决策**。即使断网，边缘端仍能独立完成安全投喂。

### 1.1 角色与权限

| 角色 | 能做什么 | 不能做什么 |
|------|---------|-----------|
| `admin`（管理员） | 全部操作，包括创建/删除农场、设备、投喂、导出 | 无 |
| `operator`（操作员） | 全部写操作（投喂、配置、告警处理） | 无 |
| `viewer`（只读） | 查看监控、告警、数据 | 不能投喂、不能修改任何配置（返回 403） |

每个用户只能访问被授权的农场（`farm_ids`），跨农场数据不可见。

## 2. 快速上手

### 2.1 登录

1. 打开浏览器，访问系统地址（如 `https://your-pond.example.com`）。
2. 使用管理员分配的账号密码登录。
3. 登录后进入**仪表盘**首页。

> **说明**：当前版本未开放自助注册，账号由系统管理员在后台创建并分配角色与农场权限。

### 2.2 首次使用三步走

1. **创建农场**：在"农场管理"页面创建您的养殖基地（见第 3 节）。
2. **注册设备**：在"设备管理"页面把边缘控制器和传感器节点登记到对应池塘（见第 4 节）。
3. **查看监控**：设备上线后，在"实时监控"页面查看水质数据（见第 5 节）。

### 2.3 仪表盘首页

仪表盘汇总展示整个基地的关键指标：

| 指标 | 含义 |
|------|------|
| 设备总数 | 已注册的设备数量 |
| 在线设备数 | 当前在线（心跳正常）的设备数量 |
| 今日投喂量 | 今日累计投喂量（转速 × 时长之和） |
| 未处理告警数 | 尚未处理的告警数量（需重点关注） |

## 3. 农场管理

农场是系统的顶层组织单元，对应一个养殖基地。每个农场下可创建多个池塘。

### 3.1 创建农场

1. 进入"农场管理"页面。
2. 点击"新建农场"。
3. 填写以下信息：

| 字段 | 必填 | 说明 |
|------|------|------|
| 名称 | ✅ | 农场名称，如"示范养殖基地" |
| 地理位置 | 否 | 如"广东湛江" |
| 面积（m²） | 否 | 农场总面积 |
| 养殖物种 | 否 | 主要养殖品种，如"罗非鱼" |

4. 点击"保存"，系统返回新农场的 ID（如 `frm_001`）。

### 3.2 编辑农场

1. 在农场列表中找到目标农场。
2. 点击"编辑"，修改信息后保存。

### 3.3 删除农场

1. 在农场列表中找到目标农场。
2. 点击"删除"，确认后删除。

> **注意**：删除农场是**不可恢复**的操作。删除前请确认该农场下已无需要保留的数据。建议先导出历史数据（见第 8 节）再删除。

## 4. 设备注册与管理

设备包括**边缘控制器**（部署在池塘现场的主控，负责投喂控制）和**传感器节点**（ESP32-S3，采集水质数据）。

### 4.1 设备自动注册

系统支持**即插即用**：边缘控制器首次连接云端时，会自动在 `device_registry` 表中登记。您只需在设备管理页面确认并补充信息即可。

### 4.2 手动注册设备

1. 进入"设备管理"页面。
2. 点击"新建设备"。
3. 填写以下信息：

| 字段 | 必填 | 说明 |
|------|------|------|
| 设备 ID | 否 | 缺省由系统生成 |
| 所属农场 | ✅ | 设备归属的农场 |
| 关联池塘 | 否 | 设备部署的池塘 |
| 设备类型 | ✅ | 如 `edge_controller`（边缘控制器）、`sensor_node`（传感器节点） |
| 状态 | 否 | `online` / `offline` |
| 固件版本 | 否 | 如 `1.0.0` |

4. 点击"保存"。

### 4.3 查看设备状态

设备列表展示每个设备的：

- **状态**：`online`（在线）/ `offline`（离线）。
- **固件版本**：当前运行的固件版本。
- **最后心跳时间**：设备最近一次上报心跳的时间（心跳间隔 30 秒）。

> **离线判断**：设备心跳超时 120 秒判定为离线，系统会生成离线告警。

### 4.4 编辑 / 删除设备

- **编辑**：修改设备信息（如固件版本、关联池塘）。
- **删除**：移除设备登记。删除前请确认设备已下线，避免数据错乱。

## 5. 实时监控

### 5.1 传感器数据

在"实时监控"页面选择目标池塘，即可查看该池塘的实时水质数据：

| 参数 | 正常范围 | 说明 |
|------|---------|------|
| pH | 6.5 - 8.5 | 酸碱度 |
| 溶解氧（DO） | ≥ 4.0 mg/L | 低于 4.0 触发告警并强制增氧 |
| 水温 | 视物种而定 | 过高（> 35°C）触发告警 |
| 氨氮（NH3） | ≤ 0.5 mg/L | 高于 0.5 触发告警 |
| 浊度 | 视水体而定 | 浑浊度 |
| 水位 | 视池塘而定 | 水位监测 |

**查看方式**：
- **最新读数**：查看最近 1 小时内每种传感器的最新值。
- **历史趋势**：选择时间范围（起止时间）和聚合窗口（1 分钟 / 5 分钟 / 1 小时 / 1 天），查看平均值曲线。

### 5.2 摄像头画面

边缘控制器通过 YOLOv8n 实时识别鱼群，输出：

- **鱼群数量**：当前画面中的鱼群数量。
- **鱼体长度**：估算的平均体长。
- **摄食行为**：聚集 / 散开 / 抢食。

摄像头关键帧（JPEG）会上传云端，可在监控页面查看。

### 5.3 实时推送

系统支持**实时推送**，无需手动刷新即可看到最新数据：

- **传感器实时流**：订阅指定池塘的传感器数据，数据到达即推送。
- **告警实时流**：订阅所有授权农场的告警事件，告警产生即推送。
- **仪表盘 WebSocket**：订阅仪表盘房间，实时更新汇总指标。

> 浏览器会自动保持连接。若长时间无数据，请检查网络或设备是否在线。

## 6. 投喂配置

系统提供三种投喂方式，您可以根据场景选择。

### 6.1 手动投喂

1. 进入"投喂"页面，选择目标池塘。
2. 点击"开始投喂"，设置投喂转速与时长。
3. 点击"确认"，指令通过 MQTT 下发到边缘控制器执行。
4. 可随时点击"停止投喂"。

> **安全说明**：手动投喂指令受硬件安全互锁约束。若溶解氧过低（< 4.0 mg/L）或水温过高（> 38°C），硬件会强制停止投喂，云端指令无法覆盖。

### 6.2 自动投喂

边缘控制器内置**模糊 PID 投喂控制器**，综合以下输入自动决策：

- 鱼群密度（摄像头识别）
- 鱼体尺寸
- 摄食强度（水面纹理分析）
- 溶解氧、水温、氨氮

控制器输出投喂电机的转速与时长，实现毫秒级精准投喂。自动投喂在边缘端本地完成，**不依赖网络**。

### 6.3 AI 推荐投喂

云端 AI 推荐引擎融合**时序预测 + 生长模型 + 强化学习策略**，生成结构化的投喂建议：

1. 进入"投喂"页面，选择目标池塘。
2. 点击"获取 AI 建议"。
3. 系统返回建议，包含：

| 字段 | 含义 |
|------|------|
| 推荐投喂率 | 建议的投喂比例 [0, 1]，如 0.8 表示 80% |
| 预计日增重 | 按当前状态预计的每日增重（g） |
| 风险等级 | LOW / MEDIUM / HIGH |
| 置信度 | [0, 1]，低于 0.7 标记"需要人工确认" |
| 建议动作 | 按优先级排序的动作列表 |
| 说明 | 建议逻辑的文字说明 |

4. **AI 建议仅供参考，不自动执行**。您确认后手动下发投喂指令。

> **重要**：AI 建议是"辅助决策"，保留养殖人员的最终决定权。当置信度低于 0.7 时，系统会明确标记"需要人工确认"，请勿盲目执行。

### 6.4 投喂日志

所有投喂操作（手动、自动、AI 推荐后执行）都会记录到投喂日志，包含：

- 投喂时间
- 投喂转速与时长
- 投喂决策详情（模糊 PID 输入/输出等）

投喂日志用于审计与后续分析，可在"投喂日志"页面按池塘筛选查看。

## 7. 告警查看与处理

### 7.1 告警类型

系统自动监测水质异常并生成告警：

| 触发条件 | 级别 |
|---------|------|
| pH < 6.5 或 > 8.5 | WARNING |
| 溶解氧 < 4.0 mg/L | CRITICAL |
| 水温 > 35°C | WARNING |
| 氨氮 > 0.5 mg/L | WARNING |
| 设备离线（心跳超时 120s） | WARNING |
| 趋势性异常（STL 残差超 3σ） | WARNING |

告警级别：`CRITICAL`（严重）/ `WARNING`（警告）/ `INFO`（信息）。

> **告警升级**：WARNING 持续 30 分钟未处理会自动升级为 CRITICAL。

### 7.2 查看告警

在"告警"页面查看告警列表，可按以下条件筛选：

- **农场**：只看某个农场的告警。
- **池塘**：只看某个池塘的告警。
- **状态**：`open`（未处理）/ `resolved`（已处理）。

每条告警包含：级别、类型、消息、产生时间、解决时间。

### 7.3 处理告警

1. 查看告警详情，确认异常原因。
2. 采取相应措施（如开启增氧、调整投喂、检查设备）。
3. 处理完成后，将告警标记为"已处理"（resolved）。

> **防告警风暴**：系统对同类告警做了去重（60 秒窗口内同类型只发一次），避免重复告警刷屏。若短时间内收到大量告警，请优先排查 CRITICAL 级别。

### 7.4 告警通知

告警可通过以下渠道通知：

- **Web 页面实时推送**（SSE 告警流）。
- **Webhook**：可配置第三方系统（如企业微信、钉钉）接收告警。

## 8. 数据导出

### 8.1 导出传感器历史数据

1. 进入"实时监控"页面，选择池塘。
2. 设置时间范围与聚合窗口。
3. 点击"导出"，系统返回聚合后的数据。

### 8.2 导出投喂日志

1. 进入"投喂日志"页面。
2. 按池塘筛选，选择时间范围。
3. 点击"导出"。

> **导出限制**：单次导出最多 10,000 行，防止超大响应。如需导出更长时间范围，请分多次导出。

### 8.3 报表（日报 / 周报 / 月报）

系统支持生成周期性报表：

| 报表 | 内容 |
|------|------|
| 日报 | 水质概要 + 投喂量 + 告警 |
| 周报 | 生长趋势 + 预测 + 建议 |
| 月报 | 成本分析 + FCR + 出塘预测 |

报表支持导出为 JSON / CSV / PDF 格式。

## 9. 数字孪生功能

数字孪生是面向**大型基地**的高阶应用（可选部署），通过时空图神经网络模拟水体环境，推演极端天气下的投喂策略。

### 9.1 虚拟水体状态

查看指定池塘的**虚拟水体状态**（仿真结果），包括温度、溶解氧、浊度、氨氮的仿真值。

### 9.2 仿真轨迹

选择极端天气场景，查看水体在场景下的仿真轨迹：

| 场景 | 描述 |
|------|------|
| `heatwave`（高温热浪） | SSP585 高温 +4°C 持续 7 天 |
| `storm_flood`（暴雨洪水） | 降雨 ×3，浊度 ×2.5 |
| `cold_snap`（寒潮） | -10°C 持续 48 小时 |

轨迹展示每个仿真步的温度、溶解氧、浊度、氨氮变化。

### 9.3 多场景对比

选择多个场景（如 `heatwave,storm_flood`），系统并行运行并返回并排摘要，对比各场景下的最终溶解氧、温度、风险等级与投喂率调整建议。

### 9.4 异常检测

将**物理传感器读数**与**虚拟基线**对比，报告超过阈值的偏差：

| 参数 | 偏差阈值 |
|------|---------|
| 溶解氧 | 1.0 mg/L |
| 水温 | 2.0°C |
| 浊度 | 10.0 NTU |
| 氨氮 | 0.2 mg/L |

当物理与虚拟偏差过大时，提示 `ANOMALY_DETECTED`，可能意味着传感器异常或水体发生未建模的变化。

> **安全说明**：数字孪生的策略推演**只在仿真环境运行**，不会在生产池塘直接执行。推演结果仅作为决策参考。

## 10. 常见问题（FAQ）

### 10.1 为什么设备显示离线？

- 检查设备供电与网络连接。
- 设备心跳间隔 30 秒，心跳超时 120 秒判定离线。
- 弱网环境下设备会自动重连（指数退避 1s → 30s），请稍候。

### 10.2 为什么看不到实时数据？

- 确认设备在线。
- 确认您有该农场的访问权限（`farm_ids`）。
- 实时推送使用 SSE/WebSocket，请确认浏览器未拦截。

### 10.3 为什么无法投喂？

- 确认您的角色是 `admin` 或 `operator`（`viewer` 无写权限）。
- 检查硬件安全互锁：若溶解氧 < 4.0 mg/L 或水温 > 38°C，硬件会强制停止投喂，云端无法覆盖。

### 10.4 AI 建议的置信度低怎么办？

- 置信度 < 0.7 时系统标记"需要人工确认"。
- 请结合现场情况人工判断，不要盲目执行。
- 可补充更多传感器数据后重新获取建议。

### 10.5 告警太多怎么办？

- 系统已做告警去重（60 秒窗口内同类型只发一次）。
- 优先处理 CRITICAL 级别告警。
- 若持续告警，请排查传感器是否异常或水质是否持续恶化。

### 10.6 如何导出历史数据？

- 在"实时监控"或"投喂日志"页面设置时间范围后导出。
- 单次导出最多 10,000 行，超长范围请分次导出。

### 10.7 数字孪生不可用？

- 数字孪生是可选部署的高阶功能，需在云端启用数字孪生引擎。
- 若引擎未就绪，相关接口返回 503，请联系运维人员。
