## 2. 核心计算平台选型

### 2.1 主控：RK3588 核心板

| 参数 | 规格 | 备注 |
|------|------|------|
| **SoC** | Rockchip RK3588 | 8nm 工艺 |
| **CPU** | 4×Cortex-A76 @ 2.4GHz + 4×Cortex-A55 @ 1.8GHz | 大小核架构 |
| **GPU** | ARM Mali-G610 MP4 | OpenGL ES 3.2 / Vulkan 1.2 |
| **NPU** | 6 TOPS (INT8) | 三核架构, 支持 INT4/INT8/INT16/FP16 |
| **RAM** | 16GB LPDDR5 | 双通道 64-bit |
| **存储** | 128GB eMMC 5.1 + MicroSD 卡槽 | 系统 + 数据分区 |
| **网络** | 双千兆以太网 (RTL8211F) + WiFi 6 (AP6275S) + BT 5.0 | 有线优先, WiFi备用 |
| **显示** | HDMI 2.1 ×1, MIPI DSI ×1 | 本地调试 |
| **摄像头** | MIPI CSI 4-lane ×2 | 支持 4K@30fps |
| **USB** | USB 3.0 ×2, USB 2.0 ×2 | 4G dongle, 外设 |
| **扩展** | 40-pin GPIO (兼容树莓派) + UART/SPI/I2C | 传感器/执行器接口 |
| **功耗** | 待机 4W / 推理 8W / 满载 12W | 被动散热片即可 |
| **系统** | Ubuntu 22.04 / Debian 12 + RKNN 2.x SDK | Go 交叉编译部署 |

**推荐核心板型号**:
- **首选**: Firefly ITX-3588J (工业级, -20~70°C)
- **备选**: Orange Pi 5 Plus (性价比, 社区活跃)
- **最低配**: NanoPi R6S (仅推理, 无 GPIO)

### 2.2 对比：RK3588 vs Jetson Orin Nano

| 维度 | RK3588 (ITX-3588J) | Jetson Orin Nano 8GB |
|------|-------------------|----------------------|
| NPU/GPU 算力 | 6 TOPS (INT8) | 40 TOPS (INT8, GPU) |
| YOLOv8n FPS | ~100 (RKNN) | ~72 (TensorRT INT8) |
| 功耗 (推理) | 8W | 15W |
| 价格 | ¥800-1200 | ¥2500-3500 |
| 生态 | RKNN (Rockchip 自研) | CUDA/TensorRT (NVIDIA 全家桶) |
| 工业温度 | -20~70°C (ITX-3588J) | -25~80°C |
| Go 交叉编译 | ✅ 简单 (ARM64) | ✅ 简单 (ARM64) |
| 7×24 可靠性 | ✅ 已验证 | ✅ 已验证 |
| 推荐场景 | **首选** — 成本敏感, 100FPS 够用 | 需要超大模型或多模型并发 |

**结论**: 优先采用 RK3588。保留 Jetson Orin Nano 作为备选（硬件引脚兼容适配器）。

### 3.1 ESP32-S3 采集节点

| 参数 | 规格 |
|------|------|
| **MCU** | ESP32-S3-WROOM-1-N16R8 |
| **CPU** | Xtensa LX7 双核 @ 240MHz |

| **WiFi** | 802.11 b/g/n (2.4GHz) |
| **固件** | ESPhome / Arduino / MicroPython |

### 3.2 传感器接线详解

```
ESP32-S3-WROOM-1-N16R8
│
├── I2C Bus (GPIO 21=SDA, GPIO 22=SCL)
│   └── TCA9548A I2C Mux (地址 0x70)
│       ├── CH0 → ADS1115 #1 (地址 0x48) → pH 传感器
│       ├── CH1 → ADS1115 #2 (地址 0x48) → 溶解氧传感器
│       ├── CH2 → ADS1115 #3 (地址 0x48) → 浊度传感器
│       └── CH3 → ADS1115 #4 (地址 0x48) → 氨氮传感器 (可选)
│
├── 1-Wire Bus (GPIO 4)
│   └── DS18B20 温度探头 (防水不锈钢封装)
│
├── Analog (GPIO 32-35, ADC1)
│   └── 水位传感器 (可选, 备用模拟输入)
│
├── Digital GPIO
│   ├── GPIO 25 → IRLZ44N MOSFET → 增氧泵继电器
│   ├── GPIO 26 → IRLZ44N MOSFET → 循环泵继电器
│   ├── GPIO 27 → 蜂鸣器 (本地告警)
│   └── GPIO 0  → 急停按钮 (INPUT_PULLUP, LOW=急停)
│
├── SPI Bus (GPIO 18=SCK, 19=MISO, 23=MOSI)
│   └── Ra-02 SX1278 (LoRa 模块, 备用通信)
│
└── Power
    ├── VIN: DC 5V (来自主配电)
    ├── 3.3V: 板载 LDO → 传感器供电
    └── GND: 公共地
```

### 3.3 ADS1115 16-bit ADC 配置

| 参数 | 设定值 | 说明 |
|------|--------|------|
| 量程 | ±4.096V | 最适传感器输出范围 |
| 采样率 | 860 SPS | 最高速度 |
| 增益 | 1× | pH 信号 0-5V 直接采集 |
| I2C 地址 | 0x48 | 通过 TCA9548A 通道选择 |
| 滤波 | 中值滤波 + EMA (α=0.3) | 平滑噪声 |

**为什么用 ADS1115 而不是 ESP32 内置 ADC?**
- ESP32 内置 ADC 仅 12-bit (4096 级)，且非线性严重
- ADS1115 是 16-bit (65536 级)，线性度 < 0.01%
- 传感器精度要求: pH ±0.11 (16-bit 足够, 12-bit 不够)

### 3.4 传感器校准流程

```
校准周期: 每 7 天 (对抗生物附着漂移)

pH 校准 (3-point):
  1. 电极浸入 pH 4.00 标准液 → 等待稳定 (60s) → 读取 ADC → 记录点1
  2. 电极浸入 pH 7.00 标准液 → 同上 → 记录点2
  3. 电极浸入 pH 10.00 标准液 → 同上 → 记录点3
  4. 线性拟合: pH = a × ADC_reading + b
  5. R² > 0.99 则校准成功

溶解氧校准 (饱和空气法):
  1. 电极暴露在饱和水蒸汽空气中 (湿海绵包裹)
  2. 等待稳定 (120s)
  3. 输入当前气压和温度 → 计算饱和溶氧值
  4. 单点校准

温度校准:
  1. DS18B20 数字传感器 → 出厂已校准
  2. 每月用 NIST 可追溯温度计验证 ±0.1°C

浊度校准:
  1. 0 NTU: 蒸馏水
  2. 100 NTU: Formazin 标准液
  3. 多点拟合 (可选 200/400/800 NTU)
```

## 4. 执行器与电源系统

### 4.1 电机驱动方案

| 执行器 | 驱动方式 | 控制信号 | 功率 | 保护 |
|--------|---------|---------|------|------|
| **投喂电机** | IRLZ44N MOSFET + PWM | GPIO 12 (PWM, 0-100% duty, 20kHz) | DC 12V, 2A (24W) | 过流保护 3A / TVS 二极管 |
| **增氧泵** | IRLZ44N + 继电器 | GPIO 14 (ON/OFF) | AC 220V, 150W | 过流保护 1A |
| **循环泵** | IRLZ44N + 继电器 | GPIO 15 (ON/OFF) | AC 220V, 200W | 过流保护 1.5A |
| **补光灯** | IRLZ44N + 继电器 | GPIO 16 (ON/OFF) | DC 12V, 10W | 过流保护 1A |

### 4.2 投喂电机 PWM 映射

```
Fuzzy-PID 输出 (0-100%) → PWM Duty Cycle → 电机转速

  0% ──→ 0% duty  ──→ 电机停止
 20% ──→ 20% duty ──→ 最低投喂速度 (维持)
 50% ──→ 50% duty ──→ 正常投喂速度
 80% ──→ 80% duty ──→ 快速投喂 (抢食高峰)
100% ──→ 100% duty──→ 最大投喂速度

安全限制:
  · 连续 100% 运行 ≤ 30s (防过热)
  · 软启动: 0% → 目标%  渐变 200ms (防机械冲击)
  · 堵转检测: 电流 > 3A 持续 2s → 急停 + 告警
```

### 4.3 急停安全回路

```
            急停按钮 (NC, 常闭)
                  │
     ┌────────────┼────────────┐
     │            │            │
     ▼            ▼            ▼
  ┌──────┐   ┌──────┐   ┌──────┐
  │电机   │   │增氧泵│   │循环泵│
  │继电器 │   │继电器│   │继电器│
  └──┬───┘   └──┬───┘   └──┬───┘
     │           │           │
     └───────────┼───────────┘
                 │
            24V 电源总线 (所有执行器供电)

逻辑:
  · 急停未按下: NC 常闭 → 继电器线圈通电 → 执行器可工作
  · 急停按下: NC 断开 → 全部继电器断开 → 全部执行器断电
  · 电源故障: 继电器线圈断电 → 全部执行器断电 (fail-safe)
  
纯硬件实现, 不依赖 MCU 或软件。
同时通知 RK3588 (GPIO 中断) → 记录 + MQTT 告警上报。
```

### 5.3 水面纹理提取 (辅助摄食强度)

```
连续 N 帧 (N=5, 间隔 200ms)
      │
      ▼
┌─────────────────────┐
│ 帧差法 (Frame Diff)  │
│ · |Frame[t] - Frame[t-1]|      │
│ · 提取运动区域        │
│ · 计算纹理能量:       │
│   E = Σ(∇I)² / area  │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
```

### 6.2 RS-485 总线规范

| 参数 | 规格 |
|------|------|
| 物理层 | RS-485 半双工, 两线制 (A+, B-) |
| 波特率 | 115200 bps |
| 协议 | Modbus RTU |
| 最大节点 | 32 (理论 256, 保守 32) |
| 最大距离 | 1200m (@ 115200 bps) |
| 终端电阻 | 120Ω at both ends |
| 偏置电阻 | 680Ω pull-up/pull-down (防浮空) |
| 线缆 | 双绞屏蔽线 2×0.5mm² + 屏蔽层接地 |

### 6.3 Modbus RTU 寄存器映射

| 寄存器地址 | 参数 | 数据类型 | 单位 | 说明 |
|-----------|------|---------|------|------|
| 0x0000 | pH 值 | Float32 (2 regs) | — | ×100 |
| 0x0002 | 溶解氧 | Float32 | mg/L | ×100 |
| 0x0004 | 水温 | Float32 | °C | ×100 |
| 0x0006 | 氨氮 | Float32 | mg/L | ×10000 |
| 0x0008 | 浊度 | Float32 | NTU | ×100 |
| 0x000A | 水位 | Float32 | cm | ×10 |
| 0x0010 | 增氧泵状态 | Uint16 | — | 0=OFF, 1=ON |
| 0x0011 | 循环泵状态 | Uint16 | — | 0=OFF, 1=ON |
| 0x0012 | 节点状态 | Uint16 | — | Bit flags |
| 0x0020 | 传感器校准 pH_a | Float32 | — | 校准系数 |
| 0x0022 | 传感器校准 pH_b | Float32 | — | 校准系数 |

### 6.4 LoRa 备用通信 (偏远鱼塘 / 4G 信号差)

| 参数 | 规格 |
|------|------|
| 模块 | Ra-02 SX1278 |
| 频率 | 433 MHz (中国 ISM 频段) |
| 功率 | 20 dBm (100mW) |
| 距离 | 视距 3-5km, 有遮挡 1-2km |
| 速率 | 0.3-37.5 kbps (扩频因子自适应) |
| 协议 | 自定义轻量协议 (减少开销) |
| 用途 | 仅传输传感器摘要数据 (1条/5min), 不传图像 |

### 7.2 热管理

```
RK3588 热设计:
  · 环境温度 -20~50°C (额定)
  · 环境温度 > 50°C → 降频 + 告警
  · 被动散热片 (铝制, 鳍片 50×50mm²)
  · 配电箱内温控风扇: > 40°C 自动开启
  · 遮阳措施: 配电箱安装在东/北侧, 或加遮阳棚

传感器探头:
  · pH/DO 探头: 0-50°C 工作, 避免阳光直射
  · 水下部分: 自然水体散热, 无热问题
  · 定期清洁探头表面生物附着 (每周巡检)
```

### 7.3 防雷与接地

```
三级防雷方案:

L1 (配电箱进线):
  └─ 浪涌保护器 SPD Type 1+2 (Imax=40kA, Up≤1.5kV)

L2 (设备电源):
  └─ 电源适配器内置 TVS 管

L3 (信号线):
  └─ RS-485 信号浪涌保护器
  └─ 网口防雷器 (RJ45 千兆)

接地系统:
  · 独立接地极: 镀锌钢管 Φ20mm × 2m, 打入地下
  · 接地电阻 < 4Ω
  · 所有金属外壳等电位连接
  · 屏蔽层单端接地 (RS-485 电缆)
```
