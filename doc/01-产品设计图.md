# y-ai-pond · 产品设计图 (Product Design Blueprint)

> **版本**: v1.0 | **日期**: 2026-07-28 | **作者**: y-ai-pond 项目组

---

## 1. 产品定位

y-ai-pond 是面向水产养殖基地的**三态智能管理平台**，覆盖边缘端（设备本地智能控制）、云端平台（数据分析与AI策略优化）、数字孪生（大型基地水体仿真与极端天气推演）三层架构。

**核心价值**：将 YOLOv8n 视觉识别、模糊PID控制、时序预测、强化学习、时空图神经网络等 AI 技术深度融入投喂管理全流程，实现从"经验投喂"到"数据驱动的精准投喂"的产业升级。

## 3. 角色与用户旅程

### 3.1 用户角色

| 角色 | 权限 | 核心场景 |
|------|------|---------|
| **管理员 (admin)** | 全部权限 | 农场创建、设备注册、用户管理、AI模型管理 |
| **操作员 (operator)** | 指定农场读写 | 日常监控、投喂管理、告警处理、报表查看 |
| **查看者 (viewer)** | 只读 | 数据查看、报表下载 |

### 3.2 核心用户旅程

#### 旅程 A：日常投喂管理

```
08:00  系统自动巡检 → 水质数据正常
08:30  摄像头启动 → YOLOv8n 检测到鱼群聚集行为（摄食预期）
08:30  Fuzzy-PID 自动启动投喂（速度 60%，预计持续 15min）
08:35  摄食强度监测 → Strong（鱼群抢食活跃）
08:40  摄食强度降至 Weak → 残饵纹理上升
08:42  Fuzzy-PID 判定投喂结束 → 电机停止
08:42  决策日志上报云端 → 操作员Dashboard查看投喂记录
```

#### 旅程 B：异常水质告警

```
14:00  传感器上报 DO=3.8 mg/L（低于4.0阈值）
14:00  边缘端安全互锁触发 → 增氧泵强制ON
14:00  云端告警引擎 → CRITICAL告警生成
14:00  操作员收到告警通知（SSE推送 + Webhook）
14:05  操作员远程查看实时数据 → 确认DO已回升至4.5
14:10  云端AI预测：未来2h DO将持续偏低 → 建议减量投喂
14:10  操作员通过Web调整今日投喂计划
```

#### 旅程 C：极端天气推演（大型基地）

```
台风预警 → 数字孪生加载 SSP585 极端天气场景
  → 仿真引擎 7天推演：水温+3°C, DO -30%, 浊度×3
  → RL策略搜索：投喂量-40%, 增氧+100%, 夜间投喂
  → 输出风险评估报告 + 应急投喂方案
  → 操作员审阅 → 采纳/调整 → 预案存档
```

## 5. 产品功能矩阵

### 5.1 边缘端功能

| 功能模块 | 功能点 | 响应时间 | 离线可用 |
|---------|--------|---------|---------|
| **YOLOv8n 视觉识别** | 鱼群计数、体长估计、行为识别、残饵检测 | < 15ms/帧 | ✓ |
| **摄食强度评估** | 水面纹理分析、光流法运动检测、强度分级（4级） | < 10ms | ✓ |
| **模糊PID控制** | 25+规则 Mamdani推理、PID增量输出、PWM电机控制 | < 5ms | ✓ |
| **安全互锁** | DO低→增氧、过流→停止、急停→全断 | < 1ms | ✓ 硬件级 |
| **MQTT通信** | Protobuf传感器、JSON指令、自动重连、本地缓冲7天 | < 50ms | ✓ |

### 5.2 云端平台功能

| 功能模块 | 功能点 | 技术 |
|---------|--------|------|
| **MQTT Gateway** | 设备接入、数据解码、自动设备注册 | paho.golang/autopaho |
| **时序数据** | 实时写入（批量5K-10K）、窗口聚合(1m/5m/1h)、最新值查询 | InfluxDB 3 |
| **业务数据** | 农场/池塘/设备管理、投喂日志、告警记录、用户权限 | PostgreSQL |
| **时序预测** | DO/温度/氨氮 24h预测、置信区间、模型漂移检测 | go-forecaster + goarima |
| **生长建模** | VBGM预测、生物能学4.0（105+物种）、FCR计算 | gonum RK4积分 |
| **RL策略优化** | DDPG 投喂策略训练(Python)、ONNX 推理(Go)、多目标奖励 | SB3 → ONNX → onnxer |
| **告警引擎** | 阈值告警、异常检测(STL)、去重(60s)、升级(WARNING→CRITICAL) | Redis + timeseries-go |
| **设备管理** | 影子(Reported/Desired)、OTA固件升级、集群健康检查 | Redis + MQTT |
| **实时推送** | SSE 传感器流、WebSocket Dashboard、房间隔离(pond_id) | Gin SSE + gorilla/ws |

### 5.3 数字孪生功能（大型基地高阶应用）

| 功能模块 | 功能点 | 技术 |
|---------|--------|------|
| **ST-GNN水体建模** | 有向图+动态邻接矩阵、多站点同步建模、多步水质预测 | D-TGCN → ONNX → onnxer |
| **物理仿真** | 温度能量平衡、DO对流扩散、氨氮累积模型 | gonum 数值方法 |
| **极端天气推演** | SSP585高温、暴雨洪水、寒潮场景、RL策略搜索 | Scenario Runner + DDPG |
| **策略输出** | 最优投喂策略、风险评估报告、多场景对比 | Simulation Engine |

## 6. 硬件架构

### 6.1 边缘端硬件选型

| 组件 | 型号 | 规格 | 备注 |
|------|------|------|------|
| **主控** | RK3588 | 8核 ARM, 6 TOPS NPU, 16GB RAM | 首选，性价比最优 |
| **备选主控** | Jetson Orin Nano | 6核 ARM, 40 TOPS GPU, 8GB RAM | NVIDIA生态 |
| **传感器节点** | ESP32-S3 | Xtensa LX7, WiFi/BLE, 16MB Flash | pH/DO/Temp/NH3/Turbidity |
| **摄像头** | IMX415 + IR-CUT | 4K 30fps, MIPI CSI-2 | 水面 + 水下 |
| **ADC** | ADS1115 ×3 | 16-bit, I2C, 860 SPS | 通过 TCA9548A mux 扩展 |
| **温度探头** | DS18B20 | 1-Wire, -55~125°C, ±0.5°C | 防水封装 |
| **电机驱动** | IRLZ44N MOSFET ×3 | N-Channel, 55V/47A | 投喂/增氧/循环泵 |

### 6.2 传感器精度矩阵

| 参数 | 型号 | 量程 | 精度 (RMSE) | 校准周期 |
|------|------|------|------------|---------|
| pH | DFRobot SEN0169 | 0-14 | ±0.11 | 每周 3-point (4/7/10) |
| 溶解氧 | DFRobot SEN0237-A | 0-20 mg/L | ±0.22 mg/L | 每周饱和空气法 |
| 温度 | DS18B20 | -55~125°C | ±0.08°C | 每月数字温度计对比 |
| 氨氮 | Analog NH3 | 0-10 mg/L | ±0.014 mg/L | 每周标准液 |
| 浊度 | DFRobot SEN0189 | 0-3000 NTU | ±1.7 NTU | 每月 Formazin 标准液 |
